inkdown

⑂ Code · repository·Notion for Markdown — write in a clean editor, ship plain .md files. Local-first desktop app: no account, no lock-in.
View code on GitHub ↗ ← Back to archive

A Markdown studio that feels like a modern notes app and leaves behind nothing but plain .md files. Local-first, offline, no account, no telemetry — your notes stay on your disk.

The library side handles multiple files and folders, search, archive and import from a file, a URL or the clipboard. The editor gives live preview, split and focus modes, a table of contents, a minimap and a word goal, with syntax highlighting for 180+ languages, KaTeX maths, mermaid diagrams, callouts and footnotes.

Past writing, it adds day-based todos with a desktop widget and a streak, slide decks built straight from ## headings with speaker notes, five-colour highlights, version history, a Ctrl+P command palette, and export to Markdown, HTML, PDF, PNG or a zip.

git clone https://github.com/hariomlohardev/inkdown && cd inkdown
pip install -r requirements.txt
python main.py

Built with PyWebView and vanilla JavaScript — Python 3.11+. Windows gets a one-click installer from Releases; any OS can run the web preview. MIT licensed.

Highlights

  • Plain `.md` files in, plain `.md` files out — no proprietary format
  • Live preview with split, focus, TOC, minimap and a word goal
  • 180+ languages highlighted, plus KaTeX, mermaid, callouts and footnotes
  • Day-based todos with a desktop widget, streak and quick capture
  • Slides generated from `##` headings, with speaker notes
  • 100% local and offline — no account, no telemetry

FAQ — inkdown
Where are my notes stored?tap ↕

On your machine, as ordinary Markdown files alongside a local inkdown-data.json. Nothing is uploaded and there is no account to create.

Do I need Windows?tap ↕

Windows gets a one-click installer from Releases. On any other OS you can run it from source with Python 3.11+, or open the web preview with npx serve app.

What happens if I stop using it?tap ↕

You keep your files. Everything is standard Markdown, so any other editor opens it — that is the point of shipping .md instead of a database.
